# Lapor Book


## App Description
Lapor Book is a mobile application used to upload public reports related to problems related to public services or government administration services.

Users must register and log in first to be able to add a report, then by writing a description and uploading supporting images, users can post reports to certain agencies. Reports that have been submitted can be viewed publicly, and commented on by anyone. Reports that are being worked on or have been completed can have their status changed by special authorized users.
